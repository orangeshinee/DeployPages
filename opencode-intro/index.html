03 · 核心概念

理解 AI 工具，只需要记住三个词：模型、Agent、Skill

A模型

AI 的「大脑」。比如 DeepSeek、Claude、GPT。它负责理解和生成内容，但不负责动手操作文件。
BAgent

AI 的「手脚」。能在你的电脑上读文件、写文件、执行命令。把"想"变成"做"。
CSkill

Agent 的「操作说明书」。你写好规则：会议纪要按什么格式输出、SQL 按什么规范写。Agent 拿着说明书干活，不会跑偏。
D类比

模型是厨师的知识，Agent 是厨师的双手，Skill 是菜谱。缺一样都做不出一道菜。

04 · 认识 OpenCode

OpenCode 不是编程工具，是一个能帮你操作文件的 AI 助手

它是什么

一个运行在电脑终端的 AI。给它一个文件夹，它会自己读文档、改文件、然后告诉你做了什么。不挑模型——可以用 DeepSeek、Claude、GPT 任意一种「大脑」。免费、开源。

为什么同事觉得它是编程工具

因为它运行在「终端」里，终端看起来像黑客电影。但实际上，你只需要用自然语言打字告诉它要什么——不需要会写一行代码。

打个比方：DeepSeek 网页版像一个你只能发微信请教的专家。OpenCode 像一个坐在你工位旁边、能直接帮你翻文件和改文档的实习生。

05 · 工具对比

五款 AI 工具横向对比，只有 OpenCode 同时满足：免费、不挑模型、能动手干活

DeepSeek 网页版 浏览器就能用，免费。但只能聊天，不能操作你的文件 适合日常问答
ChatGPT 浏览器 / App，免费或付费。部分场景可以动手，但操作范围受限 适合通用场景
OpenCode 电脑终端，免费开源。能读、能写、能执行。不挑模型 适合数字化团队
Claude Code 终端，需要 API 付费。最强编码能力，但面向开发者 适合专业开发
OpenClaw（小龙虾） 终端，免费开源。轻量编码助手，同样是面向开发者的工具 适合开发探索
Codex（OpenAI） 终端 / IDE，付费。与 Claude Code 类似，面向专业开发 适合专业开发
结论：DeepSeek / ChatGPT 像电话咨询，OpenCode 像上门服务。你想要哪个？

06 · 工作原理

打开终端、描述任务、它自己翻文件干活——就这三步

你不需要理解它是怎么调 API 的，你只需要知道：

你说

「帮我把这个需求描述转成 SQL，按品类汇总华南区过去三个月的退货率」

它做

先读你给的文档 → 理解需求 → 生成 SQL → 把每一步逻辑写成注释 → 告诉你改了哪里、为什么这样写

整个过程你只需要看和判断。你的角色从「动手的人」变成「审核的人」。
本质变化：AI 替你执行，你保留判断权

11 · 怎么开始

三步装好 OpenCode，今天下班前就能试

安装（三分钟）

① 装 Node.js：官网下载，一路下一步

② 终端输入：
npm i -g opencode-ai

③ 配置一个 API Key（DeepSeek / Claude / GPT 任一即可）

使用（从第一次就能干活）

打开你的工作文件夹，打字告诉它你要什么。不需要学语法，不需要会编程。会打字就够。

第一次建议从一个已经会做的任务开始——比如让它帮你转一条 SQL——对比你自己的写法，建立信任感。

提示：不需要「学完再用」。直接拿一个真实任务试，边用边学最快。
