## ═══════ Part 1 · 核心概念 ═══════

### Slide 04 · 三个核心概念
- **标题：** 理解 AI 工具，只需要记住三个词：模型、Agent、Skill
- **2×2 表格：**
  - A. 模型：AI 的大脑（DeepSeek / Claude / GPT）。负责理解和生成，不负责动手
  - B. Agent：AI 的手脚。能读文件、写文件、执行命令。把「想」变成「做」
  - C. Skill：Agent 的操作说明书。比如「会议纪要按什么格式输出」
  - D. 类比预告：LLM=厨师，Agent=主厨，Tool=厨具，Skill=菜谱——翻页看图

### Slide 05 · 一张图看懂 AI 智能体（全幅深色背景）
- **设计：** `background:#141413`，`padding:0`，全屏显示厨房类比大图
- **图片：** `img/kitchen-analogy.jpg`（1536×1024）
- **说明：** 无文字，纯视觉冲击——视觉层面打通「厨房」类比
- **覆盖元素：** 右上角 eyebrow，右下角页码；footer-mark 白色半透明

### Slide 06 · 厨房类比详解
- **标题：** 十个厨房角色，对应十个 AI 概念
- **表格（table.data，即带下划线的键值对列表），10 组配列：**
  - **LLM = 厨师**：有知识，但要厨具才能做菜
  - **Prompt = 点单**：描述越清晰，结果越满意
  - **Context = 厨房信息**：冰箱有什么、花生过敏——让你做对菜
  - **Tool = 厨具**：没有烤箱烤不了面包，Tool 是连接世界的接口
  - **Skill = 菜谱**：固定流程，比如「分析供应商风险：搜索→提取→评分→报告」
  - **Memory = 厨师经验**：记得你偏好的东西，不用每次都问
  - **Workflow = SOP**：麦当劳后厨，步骤固定
  - **Agent = 主厨**：能自主决策，发现没有鸡腿肉→换鸡胸肉
  - **Multi-Agent = 后厨团队**：搜索 Agent、分析 Agent、代码 Agent 各司其职
  - **MCP = 统一接口**：AI 界的 USB-C，所有工具直插即用
- **底部总结（mc 样式）：** Agent = 主厨（LLM）+ 经验（Memory）+ 厨具（Tools）+ 菜谱（Skills）+ 自主决策

### Slide 07 · 模型 vs 产品
- **标题：** 模型 ≠ 产品。一个是引擎，一个是车
- **2×2 表格：**
  - M. 模型（Model）：AI 的大脑引擎，GPT-5.5 / Claude 4 / DeepSeek V3，无界面
  - P. 产品（Product）：用户实际面对的界面，ChatGPT / Kimi / 豆包
  - B. 类比：模型是发动机，产品是整辆车。法拉利和五菱宏光发动机不同，但都能从 A 到 B
  - · 为什么重要：OpenCode 不挑发动机，可以装不同引擎
- **底部醒目标语（co 样式）：** OpenCode = 车架（Agent 系统）+ 任意发动机（模型）

## ═══════ Part 2 · 认识 OpenCode ═══════

### Slide 08 · OpenCode 是什么
- **标题：** OpenCode 不是编程工具，是一个能帮你操作文件的 AI 助手
- **双栏布局（c2）：**
  - 左栏——它是什么：AI Agent 系统，免费开源，不挑模型
  - 右栏——三种使用方式：
    - ① 终端（TUI）：经典模式，打字交互
    - ② 网页界面（Web）：`opencode web` 一键启动浏览器
    - ③ 桌面应用（Desktop）：macOS / Windows / Linux，官网下载
- **虚线框占位符：** 🖼️ [图片占位符：OpenCode 各界面截图]
- **底部比喻（mc）：** DeepSeek 网页版像只能微信请教的专家，OpenCode 像坐你工位旁能帮你翻文件改文档的实习生

### Slide 09 · 工具对比
- **标题：** 五款 AI 工具横向对比
- **数据表格（table.data），六行对比：**
  - **DeepSeek 网页版：** 浏览器，免费，只能聊天不能操作文件 → 适合日常问答
  - **ChatGPT：** 浏览器/App，免费或付费，部分场景动手但受限 → 适合通用场景
  - **OpenCode（高亮）：** 终端，免费开源，能读写能执行不挑模型 → 适合数字化团队
  - **Claude Code：** 终端，API 付费，最强编码能力 → 适合专业开发
  - **OpenClaw（小龙虾）：** 终端，免费开源，轻量编码助手 → 适合开发探索
  - **Codex（OpenAI）：** 终端/IDE，付费 → 适合专业开发
- **结论（mc）：** DeepSeek / ChatGPT 像电话咨询，OpenCode 像上门服务

### Slide 10 · 工作原理
- **标题：** 打开终端、描述任务、它自己翻文件干活——就这三步
- **双栏核心说明：**
  - 「你说」：「帮我把这个需求描述转成 SQL，按品类汇总华南区过去三个月的退货率」
  - 「它做」：先读文档 → 理解需求 → 生成 SQL → 每一步写注释 → 告诉你改了哪里
- **底部强调（mc + co 双层）：**
  - 你的角色从「动手的人」变成「审核的人」
  - 本质变化：AI 替你执行，你保留判断权
