更新日志

新功能

  1. Feature Telegram 状态消息原地编辑 - 不再追加新消息，直接更新原消息，减少聊天噪音
  2. Feature Nous Portal 一键设置 - 集成 Portal 状态 CLI 和 Nous 标记，简化配置流程
  3. Feature Webhook 安全增强 - 动态路由重载时强制 INSECURE_NO_AUTH 安全检查
  4. Feature Skills Guard 改进 - 危险操作时解释 --force 被拒绝的原因，提升透明度

Bug 修复

  1. 审批系统 - 超时/拒绝时固定"沉默不是同意"契约，防止误操作
  2. 内存保护 - 防止外部漂移影响 MEMORY.md/USER.md，确保持久化数据稳定
  3. XAI OAuth - WKE 消歧义器修复，解决认证路径的边界问题
  4. API 调用 - 中断时延迟 client.close() 到工作线程，避免资源泄露
  5. TLS/FD 处理 - 仅关闭连接不释放文件描述符，修复连接池问题
  6. QQBot 平台 - 多项稳定性改进：SILK 魔术字节、附件文件名、op 7/9 处理
  7. Gateway 运行时配置 - 环境变量模板扩展和 key_env 回退解析修复
  8. Agent 回退模型 - 规范化失败时记录警告而不是静默吞掉

安全增强

  1. Security 文件安全 - 阻止读取凭证存储文件（.env, mcp-tokens/, webhook secrets）
  2. Security 插件安全 - 防止路径遍历和 RCE 攻击，应用 truthy 环境语义
  3. Security 网关认证 - key_env 回退解析修复，确保认证失败时正确降级
  4. Security Skills Guard - 修正判决逻辑并强制 --force 限制，防止危险操作

平台改进

  1. WhatsApp - 跨 JID/LID 别名保留配对审批，解决设备切换问题
  2. Gateway Windows - .cmd 脚本原子写入，防止启动脚本损坏
  3. Telegram - 分离群组上下文处理，提升多群管理稳定性
  4. OpenCode Go - 暴露 Kimi reasoning_effort 控制，匹配 KimiProfile 形状
重要提示：本次更新包含多项安全增强，建议所有用户升级到最新版本。特别是文件安全和插件安全的改进，可以有效防止潜在的凭证泄露和代码注入风险。
