Linux 是什么

想象一下，Windows 和 macOS 是完整的汽车，出厂就带好了方向盘、车窗、雨刷。而 Linux 呢？它更像一台发动机——你可以用它组装出各种车型。专业说法：Linux 是内核，是系统的核心；而 Ubuntu、Debian、CentOS 是基于它构建的完整发行版。

为什么要学它？服务器几乎全是 Linux，程序员天天打交道，开源免费还能定制。学会它，就像掌握了计算机世界的通用语言。

类比记忆：
内核（Linux）＝ 发动机
发行版（Ubuntu 等）＝ 整车品牌
终端（Terminal）＝ 方向盘 + 仪表盘
命令（Command）＝ 操作按钮

核心概念

文件系统

Linux 的文件组织像一棵倒挂的树，所有文件和文件夹都从根目录 / 出发。

/ ← 根目录，起点
├── home/ ← 用户主目录，你的「家」
│ └── username/ ← 个人文件放这里
├── usr/ ← 系统程序
├── etc/ ← 配置文件
├── var/ ← 经常变动的数据（日志等）
└── tmp/ ← 临时文件

终端

那个黑黑的窗口就是终端。它等待你输入命令，执行后返回结果。学会它，你就掌握了和电脑「对话」的直接方式。

命令格式

命令 [-选项] [参数]
# 示例
ls -la /home          # 列出 home 目录详细内容

常用命令速查

命令 作用 示例
ls 列出文件 ls -la 详细列表
cd 切换目录 cd /home
pwd 我在哪 pwd 显示当前路径
mkdir 创建文件夹 mkdir test
touch 创建文件 touch hello.py
cp 复制 cp a.txt b.txt
mv 移动 / 重命名 mv old.txt new.txt
rm 删除 rm -rf folder 强制递归删除
cat 查看文件内容 cat hello.py
sudo 临时获取管理员权限 sudo apt install nginx
chmod 改文件权限 chmod +x run.sh
grep 搜索内容 grep "hello" *.txt
💡 小技巧：按 Tab 键自动补全，按 ↑ ↓ 翻历史命令，Ctrl+C 取消当前操作。

动手实战

跟着做，5 分钟跑完一个完整流程：

1
打开终端，输入：
mkdir linux-practice && cd linux-practice
2
创建文件并写入内容：
echo 'print("Hello, Linux!")' > hello.py
3
给文件加执行权限：
chmod +x hello.py
4
运行它：
python3 hello.py
看到输出 Hello, Linux! 了吗？恭喜你跑完了第一个 Linux 程序。
